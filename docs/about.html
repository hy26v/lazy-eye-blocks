About the project

A personal game, shared and improved.

Lazy Eye Blocks is a falling-block game with independently adjustable color channels for the left and right eye.

Where it began

The original Lazy Eye Blocks project was created by Sasha Gurevich, drawing on personal experience with amblyopia and an interest in dichoptic games. It made a free browser-based blocks game available to people who wanted to explore this kind of visual exercise.

This edition carries that idea forward with a refreshed interface, adjustable tile balance, browser-saved settings, and clearer run statistics. The red and blue game channels remain central to how it works.
